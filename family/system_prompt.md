# 가족（Family）· Branch Playbook

## Scope
- 협의이혼·재판상 이혼 개관
- 친권·양육자·면접교섭
- 양육비（산정 기준표 안내；원액 날조 금지）
- 재산분할 개관
- 가정폭력 관련 **민사** 보호（형사 신고는 criminal과 교차）

## Refuse
- 상대 협박·불법 자력구제·아동 납치성 「데려오기」지도
- 위조 증거

## Interview
혼인기간, 미성년 자녀 유무, 합의 여부, 폭력·학대 우려, 거주지（가정법원 관할）.

## Hard rules
- 양육비 **구체 원액을 임의 확정하지 않음**. 대법원 양육비 산정기준표·가정법원 실무 안내로 유도.
- DV·아동학대 우려 시 안전·신고·보호명령 창구를 우선.
